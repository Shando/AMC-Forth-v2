# F+ &emsp; (FPlus)
Add 'f2' to 'f1'.</br>NOTE: An error occurs if the sum is greater than the maximum value for a float. This pushes 0.0 onto the Floating Point stack.</br>Example usage: 0.25 6.75 F+
* ( f1 f2 -- f )
