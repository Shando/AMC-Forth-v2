# FACOS &emsp; (FACOS)
Return the principal radian angle whose cosine is 'f'.<br/>NOTE1: If abs('f') is greater than 1 this will push 0.0 onto the Floating Point stack.<br/>NOTE2: You can use RAD2DEG to convert radians to degrees.</br>Example usage: 0.25 FACOS
