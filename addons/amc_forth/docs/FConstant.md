# FCONSTANT &emsp; (FConstant)
Create a dictionary entry for <name>, associated with floating point constant x. Executing <name> places the value on the floating point stack.<br/>Example usage: 0.333 CONSTANT third
* Compile: ( 'name' x -- ), Execute: ( -- x )
