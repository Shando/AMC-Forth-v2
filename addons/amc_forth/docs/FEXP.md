# FEXP &emsp; (FEXP)
Raises e to the power of 'f'.<br/>NOTE: An error occurs if 'f1' is greater than the maximum value of a float. This pushes 0.0 onto the Floating Point stack.</br>Example usage: 0.25 FEXP
* ( f -- f1 )
