# FATAN2 &emsp; (FATAN2)
Return the principal radian angle (between -PI and PI) whose tangent is 'f1' / 'f2'.<br/>NOTE1: If 'f1' and 'f2' both equal 0.0 this pushes 0.0 onto the Floating Point stack.<br/>NOTE2: You can use RAD2DEG to convert radians to degrees.</br>Example usage: 0.33 2.0 FATAN2
* ( f1 f2 -- f )
