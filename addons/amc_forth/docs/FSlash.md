# F/ &emsp; (FSlash)
Divide 'f1' by 'f2' returning the quotient 'f3'.</br>NOTE: An error occurs if 'f2' equals zero and pushes 0.0 onto Floating Point stack.</br>Example usage: 15.5 0.25 F/
* ( f1 f2 -- f3 )
