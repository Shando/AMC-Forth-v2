# FACOSH &emsp; (FACOSH)
Return the floating point value whose hyperbolic cosine value is 'f'.<br/>NOTE: If 'f' < 1 this will push 0.0 onto the Floating Point stack.</br>Example usage: 1.25 FACOSH
* ( f -- f )
