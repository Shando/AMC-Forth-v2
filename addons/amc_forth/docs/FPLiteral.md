# FPLITERAL &emsp; (FPLiteral)
At execution time, remove the top floating point number from the Floating Point stack and compile into the current definition. Upon executing <name>, place the floating point number on the top of the Floating Point stack.
* Compile:  ( f -- ), Execute: ( -- f )
* [Source Code](../words/floating_point/FPLiteral.cs)
* Execution Tokens: 1264573544 (interpreted) and 727702632 (compiled)
