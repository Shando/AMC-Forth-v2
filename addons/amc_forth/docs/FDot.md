# F. &emsp; (FDot)
Display, in the console, the top number on the floating-point stack using fixed-point notation: [-]<digits>.<digits>.<br/>NOTE1: This displays with a trailing space automatically.<br/>NOTE2: An error occurs if the value of BASE is not (decimal) ten. This will leave the stack as is.<br/>Example usage: 123456789.123 F.
* ( f -- )
