# F* &emsp; (FStar)
Multiply 'f1' by 'f2' returning the product 'f3'.</br>NOTE: An error occurs if 'f3' is outside the bounds of a float. This pushes 0.0 onto Floating Point stack.</br>Example usage: 0.25 6.5 F*
* ( f1 f2 -- f3 )
