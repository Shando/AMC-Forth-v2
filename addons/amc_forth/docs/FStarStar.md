# F** &emsp; (FStarStar)
Raise 'f1' to the power 'f2' returning the product 'f3'.</br>NOTE: An error occurs if 'f3' is outside the bounds of a float. This pushes 0.0 onto Floating Point stack.</br>Example usage: 25.5 2.0 F**
* ( f1 f2 -- f3 )
