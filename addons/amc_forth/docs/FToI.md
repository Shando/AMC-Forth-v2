# F&gt;I &emsp; (FToI)
Returns the equivalent of the integer portion of 'f'.</br>NOTE1: The fractional portion of 'f' is discarded.</br>NOTE2: Rounding the floating point value prior to calling F>I is advised, as F>I rounds towards zero.</br>Example usage: 25.25 F>I
* ( f -- n )
