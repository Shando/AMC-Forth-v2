# FLITERAL &emsp; (FLiteral)
At execution time, remove the top floating point number from the Floating Point stack and compile into the current definition. Upon executing 'name', place the floating point number on the top of the Floating Point stack.</br>Example usage: third 0.333 FLITERAL
* Compile:  ( f -- ), Execute: ( -- f )
* [Source Code](../words/floating_point/FLiteral.cs)
* Execution Tokens: 1079862456 (interpreted) and 542991544 (compiled)
