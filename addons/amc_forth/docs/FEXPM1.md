# FEXPM1 &emsp; (FEXPM1)
Raises e to the power of 'f' and subtracts 1.<br/>NOTE: An error occurs if 'f1' is greater than the maximum value of a float. This pushes 0.0 onto the Floating Point stack.</br>Example usage: 0.25 FEXPM1
* ( f -- f1 )
